# World Heritage Atlas 機能仕様書

## 1. 文書情報

- 文書種別: MVP機能仕様書
- 対象アプリ: World Heritage Atlas
- 目的: 世界遺産の英語情報を読み、語彙を記録・復習しながら英語力を鍛える
- 利用者: 開発者本人1名
- 認証: 実装しない
- 対象端末: PCブラウザとスマートフォンブラウザ
- 既存構成: React + TypeScript + Vite / NestJS + TypeORM / Neon Postgres

## 2. プロダクトの基本方針

1. ランダムに出会った世界遺産について、まず英語で読む。
2. 必要なときだけ日本語訳を確認する。
3. 分からない単語・句動詞を、出典となる英文と一緒に保存する。
4. 読んだ世界遺産と理解度を記録し、学習量を振り返れるようにする。
5. 個人用アプリとして、設定や管理を複雑にしない。

## 3. MVPの対象機能

- ランダムな世界遺産の表示
- 「すべて」と「有名な世界遺産」の抽選モード
- 英語情報、画像・映像、基本情報の表示
- 英文の日本語訳表示切り替え（DeepL API）
- 英文読み上げ
- 読了記録と閲覧履歴
- 世界遺産ごとの理解度記録
- お気に入り
- 後で読む
- 単語・句動詞の選択、翻訳、保存
- 保存語彙の一覧・詳細・削除
- 保存語彙の暗記カード
- 「暗記対象」と「まだ不安」の独立管理
- 学習記録ページ

## 4. 対象外

初回実装では次を対象外とする。

- ログイン、複数ユーザー、端末間のユーザー切り替え
- SNS共有、ランキング、他ユーザーとの交流
- AIによる読解問題生成
- 単語の間隔反復テスト
- プッシュ通知
- 世界地図の塗り分け表示
- 管理画面からの世界遺産データ編集
- ネイティブアプリ化

## 5. 画面構成

### 5.1 ホーム

表示項目:

- アプリの説明
- 「ランダムに読む」ボタン
- 抽選モード選択
  - すべて
  - 有名な世界遺産
- 学習サマリー
  - 読了したユニーク世界遺産数
  - 総読了回数
  - 保存語彙数
  - お気に入り数
  - 後で読む件数
- 最近読んだ世界遺産（最大5件）
- 各主要ページへの導線

抽選モードはブラウザに保存し、次回アクセス時も前回の値を初期選択する。

### 5.2 世界遺産リーダー

ランダムに取得した1件を表示する、アプリの中心画面。

表示項目:

- 英語名
- 国・地域
- カテゴリ（文化・自然・複合）
- UNESCO ID
- メイン画像
- 追加画像または映像（存在する場合のみ）
- 英語の概要・説明
- 登録年
- 登録基準
- 面積
- 危機遺産かどうか
- 緯度・経度
- 画像・映像の作者、ライセンス、出典

操作:

- 次の世界遺産へ
- 日本語訳を表示／英語だけに戻す
- AIで全文翻訳（ChatGPTを新しいタブで開く）
- 英文を読み上げる／一時停止／停止
- 理解度を選択
- 読了にする
- お気に入りの追加／解除
- 後で読むの追加／解除
- 単語記録モードの開始／終了

UNESCOデータに画像がない場合はWikipedia APIで該当記事の代表画像を取得し、画像URL、作者、ライセンス、元記事URLをDBへ保存して補完する。Wikipediaでも画像を取得できない場合、または画像読み込みに失敗した場合は共通プレースホルダーを表示する。映像がない場合は映像欄自体を表示しない。

### 5.3 学習記録

表示項目:

- 読了したユニーク世界遺産数
- 総読了回数
- 閲覧したユニーク世界遺産数
- 保存語彙数
- 理解度別の件数
- カテゴリ別読了件数
- 地域別読了件数
- 最近の読了履歴

一覧から該当する世界遺産の詳細を再表示できる。

### 5.4 保存語彙

一覧表示項目:

- 保存した英語表現
- 文脈に合った日本語訳
- 保存元の世界遺産名
- 保存日

機能:

- 新しい順／古い順／アルファベット順で並べ替え
- 単語または訳で検索
- 世界遺産で絞り込み
- 詳細表示
- 削除
- 同一表現の重複保存防止

詳細表示項目:

- 選択した単語または句動詞
- 日本語訳
- 元の英文1文
- 世界遺産名
- 保存日
- 読み上げボタン

### 5.5 お気に入り

お気に入りに登録した世界遺産を一覧表示する。お気に入りは「特に好き、また見たい世界遺産」を表す。

### 5.6 後で読む

後で読むに登録した世界遺産を一覧表示する。「まだ読了していないが、後で読みたい世界遺産」を表す。

読了時に後で読むから自動削除するかはユーザー設定にせず、MVPでは自動削除する。必要なら読了後に再登録できる。

### 5.7 暗記カード

保存した語彙は初期状態で暗記カードに追加する。カード中央に英単語・句動詞を表示し、カードのタップまたはEnterキーで日本語訳を表示する。もう一度タップまたはEnterキーを押すと次のカードへ進む。

- 「覚えた」操作で、その語彙を暗記カードから外す。
- 「もう一度暗記する」操作で、単語帳から暗記カードへ戻せる。
- 1周が終わったら学習件数を表示し、もう一度開始できる。
- 暗記対象が0件の場合は単語記録モードへの導線を表示する。

保存語彙には以下の2状態を持たせ、必ず独立して変更する。

- `isInMemorization`: 暗記カードに出すか。保存時は `true`。
- `isUncertain`: まだ不安な表現か。保存時は `true`。

暗記カードで「覚えた」を押しても `isUncertain` は変更しない。「不安ではない」に変更しても `isInMemorization` は変更しない。

## 6. 機能詳細

### 6.1 ランダム抽選

- 抽選のたびに対象データから1件をランダム取得する。
- 過去に表示・読了した世界遺産も抽選対象に含める。
- 直前に表示していた1件だけは、候補が2件以上ある場合には連続表示しない。
- `all` モードは全件を対象にする。
- `famous` モードは `isFeatured = true` のデータだけを対象にする。
- 有名かどうかは公式分類ではないため、アプリ内で管理する独自フラグとする。
- famousの初期データは、開発時に代表的な世界遺産を手動選定する。
- 対象データが0件の場合はエラー画面ではなく、条件を変更する案内を表示する。

「次の世界遺産へ」を押しただけでは読了扱いにしない。

### 6.2 閲覧・読了記録

- 世界遺産リーダーに1件が正常表示された時点で閲覧を記録する。
- 同一ページの再レンダリングや日本語訳の切り替えでは閲覧回数を増やさない。
- 「読了にする」を押した時点で読了履歴を1件追加する。
- 同じ世界遺産を再読した場合も総読了回数は増やす。
- ユニーク読了数は同じ世界遺産を何度読んでも1件として数える。
- 読了済み世界遺産では「もう一度読了として記録」と分かる表示にする。
- 読了操作は誤操作対策として、押下後の短時間に取り消せるトーストを表示する。

### 6.3 理解度

世界遺産の記事単位で、次の3段階を記録する。

- `difficult`: 難しかった
- `partial`: だいたい分かった
- `understood`: よく分かった

仕様:

- 未選択も許可する。
- 選択すると即時保存する。
- 同じ世界遺産で再選択した場合は最新値で上書きする。
- 理解度は読了前でも選択できる。
- 学習記録ページでは現在の最新理解度で集計する。

### 6.4 日本語訳切り替え

- 初期表示は常に英語のみとする。
- 「日本語訳を表示」を押すと、英語原文を残したまま各段落の直下に日本語訳を表示する。
- ボタンを再度押すと日本語訳だけを非表示にする。
- 翻訳対象は英語名、概要、説明、登録基準の説明、画像キャプションとする。
- 国名、数値、固有のメタデータは原則として翻訳APIへ送らない。
- 翻訳はDeepL APIをバックエンド経由で実行する。
- DeepL APIキーをフロントエンドへ返さない。キーはバックエンドの環境変数 `DEEPL_API_KEY` に保存する。
- `DEEPL_API_BASE_URL` を環境変数化し、契約プランに応じてAPIホストを切り替えられるようにする。
- 翻訳結果は原文と対象言語をキーにDBへ保存し、同じ原文を毎回翻訳しない。
- 原文が更新された場合は、新しい原文のハッシュにより再翻訳する。
- 複数段落は段落対応を維持して一括翻訳し、API呼び出し数を抑える。
- API失敗時も英語記事は閲覧可能にし、「翻訳を取得できませんでした。再試行」のみ表示する。
- 読み込み中は翻訳領域にスケルトンまたは進捗表示を出す。

### 6.4.1 ChatGPTで全文翻訳

- DeepLのアプリ内表示とは別に「AIで全文翻訳」ボタンを設ける。
- ボタン押下時に、世界遺産名、国、概要、説明、登録理由、登録基準を含む日本語の翻訳依頼プロンプトを生成する。
- `https://chatgpt.com/?prompt=<URLエンコードしたプロンプト>` を新しいタブで開き、利用者自身のChatGPTへ渡す。
- プロンプトでは全文翻訳、固有名詞への英語併記、重要語彙・句動詞の抽出、事実を創作しないことを指示する。
- ChatGPT APIキーやOpenAI API連携は使用しない。

### 6.5 英文読み上げ

- MVPではブラウザ標準の Web Speech API (`speechSynthesis`) を使用する。
- 読み上げ対象は英語名、概要、説明本文とする。
- 操作は「再生」「一時停止／再開」「停止」を提供する。
- 速度は `0.75 / 1.0 / 1.25` から選択できる。
- 英語音声を優先し、利用可能なら `en-US` または `en-GB` を選択する。
- ページ移動、「次の世界遺産へ」、コンポーネント破棄時には読み上げを停止する。
- 日本語訳を表示していても読み上げ対象は英語のみとする。
- 選択した保存語彙と元の英文も個別に読み上げられる。
- 対応音声がないブラウザでは、読み上げボタンを無効化して理由を表示する。

### 6.6 単語・句動詞の記録

#### 選択方法

- 単語記録モード中、PCではクリックまたはダブルクリックで単語を選択できる。
- 句動詞・複数語表現は、マウスドラッグまたはタッチ端末の長押し選択で範囲指定できる。
- 通常の文字列選択も妨げない。
- 選択できるのは英語名、概要、説明本文、登録基準の説明内の英語テキストのみ。
- 空白だけ、句読点だけ、極端に長い範囲は保存できない。
- MVPの最大選択長は100文字とする。

#### 保存フロー

1. ユーザーが英語表現を選択する。
2. 選択範囲の近くに「訳を見る」ポップオーバーを表示する。
3. バックエンドがDeepL APIで日本語訳を取得する。
4. ポップオーバーに選択表現、訳、元の英文を表示する。
5. ユーザーが「単語帳に保存」を押す。
6. 保存完了トーストを表示する。

保存項目:

- 選択した原文（前後空白を除去した文字列）
- 検索・重複判定用の正規化文字列
- 日本語訳
- 選択箇所を含む元の英文1文
- 世界遺産ID
- 本文内のセクション種別
- 保存日時

翻訳時には、単語だけを単独送信するのではなく元の英文を文脈として利用する。DeepL APIの利用機能で文脈指定が可能な場合はそれを使い、不可能な場合も選択語と元文の対応が崩れない形式で送る。

同じ世界遺産で同じ正規化表現が既に保存済みの場合は重複保存せず、「保存済み」と表示する。別の世界遺産で同じ表現を選んだ場合も、MVPでは語彙項目は1件にまとめ、出典を追加する。

### 6.7 お気に入り

- 世界遺産単位でON/OFFを保存する。
- 読了状態とは独立させる。
- リーダー画面とお気に入り一覧のどちらからも解除できる。
- 同じ世界遺産を重複登録しない。

### 6.8 後で読む

- 世界遺産単位でON/OFFを保存する。
- お気に入りとは独立させる。同時登録も可能。
- 読了を記録した時点で後で読むから自動解除する。
- 同じ世界遺産を重複登録しない。

## 7. データ設計案

既存の `world_heritage_site` 相当テーブルを維持し、次を追加する。

### 7.1 WorldHeritageSiteへの追加

- `isFeatured: boolean` — 有名な世界遺産か

- `id`
- `heritageSiteId`
- `viewedAt`

### 7.3 HeritageRead

- `id`
- `heritageSiteId`

### 7.4 HeritageLearningState

- `heritageSiteId`（一意）
- `comprehensionLevel`（nullable）
- `isFavorite`
- `isReadLater`
- `updatedAt`

単一利用者のため `userId` は持たない。

### 7.5 SavedVocabulary

- `id`
- `expression`
- `normalizedExpression`（一意）
- `translationJa`
- `isInMemorization`（保存時は `true`）
- `isUncertain`（保存時は `true`）
- `createdAt`
- `updatedAt`

### 7.6 VocabularySource

- `id`
- `vocabularyId`
- `heritageSiteId`
- `sourceSentenceEn`
- `sectionType`
- `createdAt`

1つの表現に複数の出典文を関連付ける。

### 7.7 TranslationCache

- `id`
- `sourceLanguage`
- `targetLanguage`
- `sourceTextHash`
- `sourceText`
- `translatedText`
- `provider`（`deepl`）
- `createdAt`
- `updatedAt`

`sourceLanguage + targetLanguage + sourceTextHash + provider` を一意にする。

## 8. API設計案

URLは既存構成に合わせて `/api` 配下で公開する。

### 世界遺産

- `GET /api/heritage/random?mode=all|famous&exclude=<uuid>`
- `GET /api/heritage/:id`
- `POST /api/heritage/:id/views`
- `POST /api/heritage/:id/reads`
- `DELETE /api/heritage/:id/reads/:readId` — 直後の取り消し用

### 学習状態

- `GET /api/heritage/:id/learning-state`
- `PATCH /api/heritage/:id/comprehension`
- `PUT /api/heritage/:id/favorite`
- `DELETE /api/heritage/:id/favorite`
- `PUT /api/heritage/:id/read-later`
- `DELETE /api/heritage/:id/read-later`

### 翻訳

- `POST /api/translations/article`
  - 世界遺産IDを受け取り、翻訳済みの各フィールドを返す。
- `POST /api/translations/selection`
  - 選択表現、元の英文、世界遺産IDを受け取り、文脈に合う日本語訳を返す。

任意のURLや自由な巨大テキストを中継する汎用翻訳APIにはしない。入力長、対象言語、レートをバックエンドで制限する。

### 語彙

- `GET /api/vocabulary`
- `POST /api/vocabulary`
- `GET /api/vocabulary/:id`
- `DELETE /api/vocabulary/:id`
- `PATCH /api/vocabulary/:id/learning-state`
  - `isInMemorization` と `isUncertain` をそれぞれ独立して更新する。

### 一覧・統計

- `GET /api/favorites`
- `GET /api/read-later`
- `GET /api/history`
- `GET /api/stats`

## 9. UI状態とエラー処理

- データ取得中は現在のレイアウトを維持したスケルトンを表示する。
- 「次の世界遺産へ」を連打しても重複リクエストを送らない。
- 取得失敗時は再試行ボタンを表示する。
- 翻訳、学習状態、語彙保存の失敗はページ全体をエラー画面にしない。
- 保存系操作は成功・失敗をトーストで通知する。
- 楽観的更新を使用する場合、失敗時には表示を元に戻す。
- 画像の読み込み失敗時はプレースホルダーへ切り替える。
- 空の一覧には、理由とリーダー画面への導線を表示する。

## 10. セキュリティ・運用

- DeepL APIキーはバックエンド環境変数だけに置く。
- `.env` をGitへコミットしない。
- `.env.example` には値を入れず、必要な変数名だけ追加する。
- 翻訳APIに入力長制限と簡易レート制限を設ける。
- APIエラーのレスポンスやログにDeepL APIキーを含めない。
- 外部画像・映像はライセンス、作者、出典を確認できる情報と一緒に扱う。
- 個人利用でもDBバックアップを可能にしておく。

## 11. 非機能要件

- スマートフォン幅でも本文、選択ポップオーバー、主要ボタンが操作できる。
- キーボードだけで主要操作が可能である。
- ボタンに適切なラベルとフォーカス表示を持たせる。
- 色だけで理解度や状態を表現しない。
- API応答を待つ間にも二重送信を防ぐ。
- 外部APIが停止しても英語本文の閲覧、読了、お気に入りは利用できる。
- 既存のUIトーン、配色、タイポグラフィを維持する。

## 12. 受け入れ条件

### ランダム表示

- all/famousを選んで1件取得できる。
- famousでは `isFeatured = true` 以外が表示されない。
- 直前の1件を除外して次を取得できる。

### 日本語訳

- 初期状態では日本語訳が表示されない。
- 操作すると英語を残したまま日本語訳が表示される。
- 同じ原文の2回目以降は保存済み翻訳を返せる。
- DeepL障害時も英語本文を読める。

### 読み上げ

- 英文を再生、一時停止、再開、停止できる。
- 次の世界遺産へ移動すると読み上げが停止する。
- 読み上げ速度を変更できる。

### 記録

- 閲覧と読了を別々に記録できる。
- 同じ世界遺産の再読が総読了回数に反映される。
- ユニーク読了数は重複しない。
- 理解度の最新値を保存・集計できる。

### お気に入り・後で読む

- それぞれ独立して登録・解除できる。
- 読了時に後で読むが解除される。

### 語彙

- 1単語と複数語表現の両方を選択できる。
- 文脈に合った訳を取得し、元文と一緒に保存できる。
- 同一表現は1件にまとめ、別の出典を追加できる。
- 一覧、検索、詳細表示、削除ができる。

### 暗記カード

- 保存直後の語彙が暗記カードに表示される。
- カードのタップまたはEnterで「英語 → 日本語 → 次の英語」と進められる。
- 「覚えた」で暗記対象から外れ、単語帳から暗記対象へ戻せる。
- 暗記対象を変更しても「まだ不安」は変化しない。
- 「まだ不安」を変更しても暗記対象は変化しない。

### 外部メディア・ChatGPT

- UNESCO画像がない場合にWikipedia画像、作者、ライセンス、元記事URLを保存・表示できる。
- Wikipedia取得失敗時も英語記事を表示できる。
- 「AIで全文翻訳」のリンクに、その世界遺産の全文を含むURLエンコード済みプロンプトが設定される。
